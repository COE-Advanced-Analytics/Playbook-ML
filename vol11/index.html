¿Cuándo usar Regresión vs Clasificación?

La primera decisión en cualquier modelo. Equivocarte aquí invalida todo lo demás.

🎯 El problema que resuelve

Los equipos piden modelos sin definir bien qué tipo de respuesta necesitan. Elegir la técnica equivocada invalida el modelo completo, sin importar cuántos datos tengas. La pregunta de negocio determina la herramienta, no al revés.

📏 Regresión — "¿Cuánto?"
  • ✓
    La respuesta es un número continuoSoles, cajas, %, días, toneladas
  • ✓
    Necesitas magnitud exactaPara planificar producción, presupuesto o precios
  • ✓
    Decisión depende del valor"¿Cuánto producir?" necesita un número, no una etiqueta
  • ✓
    Mides error en la misma unidadSi fallas en 500 cajas, el impacto es concreto
  • ✓
    Ejemplos AlicorpVentas de Don Vittorio por semana · Impacto en soles de una promo · Precio óptimo de AlaCena
🏷️ Clasificación — "¿A qué grupo?"
  • ✓
    La respuesta es una etiquetaSí/No · Alto/Medio/Bajo · Segmento A/B/C
  • ✓
    Necesitas asignar a un grupoPara tomar acción diferenciada por tipo de cliente
  • ✓
    Decisión es por pertenencia"¿A quién visitar primero?" no requiere un número
  • ✓
    Mides si acertaste la categoría¿Detecté correctamente al cliente en riesgo?
  • ✓
    Ejemplos AlicorpBodega en riesgo de churn · Segmento de cliente · ¿Comprará Insuma esta semana?
🧴
Ejemplo: Gestión de clientes canal tradicional
Regresión Planificación de demanda
📦 "¿Cuántas cajas de Primor pedirá esta bodega?"
🔢 Respuesta: 142 cajas — número exacto, planificable
Sin modelo — error promedio ±35% Sobrestock o quiebre de inventario
Clasificación Priorización de visitas
🚨 "¿Esta bodega está en riesgo de dejar de comprarnos?"
🏷️ Respuesta: ALTO RIESGO → asignar asesor esta semana
Con modelo — retención lograda +25% Más clientes retenidos a tiempo
💡
La clave: Ambas preguntas usan los mismos datos del cliente, pero la respuesta que necesita el negocio define todo. Si necesitas un número → regresión. Si necesitas una acción diferenciada → clasificación.
⚠️
Error común: Convertir ventas en "Alto / Medio / Bajo" para simplificar
❌ Lo que hacen

"Las ventas proyectadas son 138 cajas... mejor ponemos 'Alto' para que se entienda."

✓ La realidad

Perdiste información útil. El modelo ya no sabe si 138 es mejor o peor que 120. Usa el número si el negocio lo necesita para decidir.

Regla de oro: Antes de modelar, hazte UNA pregunta: ¿la respuesta que necesito el negocio es un número o una etiqueta? Si es un número (ventas, impacto, precio) → regresión. Si es una categoría (riesgo, segmento, propensión) → clasificación. Todo lo demás es ejecución.
